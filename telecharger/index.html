Téléphone Android

Installez l'application sur votre téléphone. Les mises à jour arrivent ensuite toutes seules.

Télécharger l'application
Fichier AMOD-Academy.apk · environ 70 Mo · version 2.13
  1. Appuyez sur « Télécharger l'application » et attendez la fin du téléchargement.
  2. Ouvrez le fichier téléchargé (dans la notification ou dans « Mes fichiers » › « Téléchargements »).
  3. Si le téléphone le demande, autorisez l'installation : appuyez sur « Paramètres », activez « Autoriser cette source », puis revenez en arrière.
  4. Appuyez sur « Installer », puis sur « Ouvrir ». Créez votre compte et commencez.
Le message « application inconnue » est normal : l'application est distribuée directement par AMOD GROUP, en dehors du Play Store. Téléchargez-la uniquement depuis cette page officielle.

iPhone et ordinateur

Sur iPhone, AMOD Academy s'utilise directement dans Safari, sans rien télécharger.

Ouvrir AMOD Academy
  1. Ouvrez cette page dans Safari et appuyez sur « Ouvrir AMOD Academy ».
  2. Appuyez sur le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisissez « Sur l'écran d'accueil », puis « Ajouter ». L'icône AMOD Academy apparaît comme une vraie application.
